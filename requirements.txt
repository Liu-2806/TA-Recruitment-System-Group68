Shared Environment Requirements

1. Required Environment

- Operating System: Windows 10 or Windows 11
- Java: JDK 21
- Servlet API: javax.servlet 4.x compatible container
- Shell: PowerShell
- Encoding: UTF-8

- lib/pdfbox-app-3.0.2.jar
- lib/gson-2.11.0.jar
- lib/javax.servlet-api-4.0.1.jar

4. Current Module Scope

The currently completed owned modules are:
- PDF resume input module
- structured resume extraction module
- LLM / local-rule job matching module
- MO backend profile / posting / applicant-review module

These modules are implemented in:
- src/com/bupt/ta/
- web/
- data/

Current frontend root note:
- use `web/` as the active JSP and static asset root
- historical `src/main/webapp` references in logs are not the current runtime directory

5. Compile Check Command

Run this command in the project root to verify the current module compiles:

powershell -ExecutionPolicy Bypass -Command "javac -encoding UTF-8 -cp 'lib/pdfbox-app-3.0.2.jar;lib/gson-2.11.0.jar;lib/javax.servlet-api-4.0.1.jar' -d build/module-check (Get-ChildItem -Recurse -Filter *.java src/com/bupt/ta | ForEach-Object { $_.FullName })"

MO backend smoke test compile command:

$files = @((Get-ChildItem -Recurse -Filter *.java src\com\bupt\ta | ForEach-Object { $_.FullName })) + @('src\test\java\com\bupt\ta\MOBackendSmokeTest.java')
javac -encoding UTF-8 -cp "lib/pdfbox-app-3.0.2.jar;lib/gson-2.11.0.jar;lib/javax.servlet-api-4.0.1.jar" -d build/mo-smoke-classes $files

MO backend smoke test run command:

java -cp "build/mo-smoke-classes;lib/pdfbox-app-3.0.2.jar;lib/gson-2.11.0.jar;lib/javax.servlet-api-4.0.1.jar" com.bupt.ta.MOBackendSmokeTest

Smoke test note:
- it copies `data/` to `build/mo-smoke-data/data`
- it verifies MO profile, job posting, applicant review, status update, and resume download without mutating the root `data/`

MO manual console verification command:

powershell -ExecutionPolicy Bypass -File scripts\run-mo-console.ps1

Manual console note:
- it compiles the current MO backend related source files
- it copies `data/` to `.mo-console/data` by default
- it stores downloaded resumes in `.mo-console/downloads`

6. Optional LLM Configuration

If API-based matching is needed, configure:
- LLM_API_URL
- LLM_API_KEY
- LLM_MODEL

Recommended private setup:
- copy .env.example to .env.local
- edit .env.local locally
- do not commit .env.local

The code supports both environment variables and .env.local loading.

Supported DeepSeek base URL forms:
- https://api.deepseek.com
- https://api.deepseek.com/v1

7. Data Constraint Reminder

According to the handout:
- use Java or Java Servlet/JSP
- use text-based files only
- do not use a database

Allowed project data files include:
- .txt
- .csv
- .json
- .xml

8. Collaboration Rule

After each code change, update these files together:
- README.md
- requirements.txt
- docs/简历输入模块中文说明手册.md
- docs/代码结构树.md

9. New Member Setup Steps

1. Pull the latest repository.
2. Install JDK 21.
3. Make sure the three JAR files in lib/ exist.
4. Copy .env.example to .env.local if LLM mode is needed.
5. Import the project into the team IDE setup or run the compile check command above.
6. Do not commit local API secrets or local build output.
