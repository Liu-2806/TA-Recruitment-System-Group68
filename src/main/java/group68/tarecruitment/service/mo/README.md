# MO Services

Responsibilities:

- prepare MO dashboard summary
- manage MO profile
- create and update postings
- list applicants for one posting
- compute or return applicant match data
- accept and reject applicants

Suggested classes:

- `MoDashboardService`
- `MoProfileService`
- `MoPostingService`
- `MoApplicantService`

Important details:

- decisions must update both posting and application records
- active posting summary should include applicant counts
