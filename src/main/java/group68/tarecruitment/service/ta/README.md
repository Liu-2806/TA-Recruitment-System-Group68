# TA Services

Responsibilities:

- prepare dashboard summary data
- manage TA profile and skill tags
- handle CV upload metadata
- search and filter positions
- validate and create applications
- list application history

Suggested classes:

- `TaDashboardService`
- `TaProfileService`
- `TaPositionService`
- `TaApplicationService`

Important details:

- application creation should later check duplicates and schedule conflicts
- dashboard data should aggregate profile, posting, and application information
