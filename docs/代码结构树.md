## 目录职责说明

- `src/com/bupt/ta/config/`
  统一装配 service 与 repository，避免各控制器自己 new 依赖。

- `src/com/bupt/ta/controller/ta/`
  TA 侧与输入模块、岗位匹配展示直接相关的控制器入口。

- `src/com/bupt/ta/controller/mo/`
  MO 侧查看申请人、查看匹配结果、下载简历的控制器入口。

- `src/com/bupt/ta/resume/`
  简历解析与结构化提取逻辑。

- `src/com/bupt/ta/match/`
  匹配结果计算、LLM 调用、fallback 逻辑与匹配结果封装。

- `src/com/bupt/ta/repository/file/`
  基于 JSON 文本文件的数据访问层。

- `src/com/bupt/ta/service/impl/`
  本次已接入的输入模块、匹配模块和申请联动实现。

- `data/`
  文本数据文件目录，符合 handout 的“无数据库”约束。

- `web/WEB-INF/views/`
  当前主框架使用的 JSP 视图目录。

## 维护要求

每次新增、删除、移动与本模块相关的文件后，都必须同步更新本文档。
