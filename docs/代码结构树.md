## 目录职责说明

- `src/com/bupt/ta/`
  当前业务主框架，包含 controller、service、repository、resume、match 等 Java 代码。
  其中 `match/` 目录当前同时承载本地规则匹配与带解释性约束的 LLM prompt 匹配实现。

- `src/test/java/`
  当前保留的测试辅助代码与样例生成代码。

- `web/`
  当前统一的前端根目录，包含预览入口、静态资源、JSP 视图、taglib 依赖和 `web.xml`。

- `data/`
  文本数据文件目录，符合 handout 的“无数据库”约束。

- `docs/`
  项目阶段文档、模块说明和结构说明。

- `work-log.md`
  阶段性工作记录，保留目录演化过程与开发决策。

## 维护要求

每次新增、删除、移动与当前主框架相关的文件后，都必须同步更新本文档。
